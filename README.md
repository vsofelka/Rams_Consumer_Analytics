# Rams Consumer Analytics

A project built for an application to the Los Angeles Rams' **Intern, Marketing Analytics & Consumer Insights** role. See [`docs/job_description.md`](docs/job_description.md) for the full posting.

**Status: direction not yet finalized.** See [`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md) for the full background, candidate directions under consideration, and open decisions.

## What this will be

A model that helps the Rams act on fan behavior *during* the season, not just in a preseason planning exercise — likely one of:

- Renewal/churn risk scoring for season ticket holders
- A rolling fan engagement score
- Purchase/upsell propensity modeling

Exactly one of these will be built end-to-end, updating on a recurring cadence as new data comes in. See `PROJECT_CONTEXT.md` for the reasoning and current thinking.
